# 단위 테스트

파일은 `<대상>.test.ts(x)`, 실행은 `vitest --run <파일>`.

## 우선 대상 - 눈으로 확인 못 하는 것부터

1. 검증 - 규칙별 경계값(0, 1, 최댓값, 빈값, 공백). 빈값이 required 외 규칙을 통과하는지.
2. 변환 - 입력 → 출력 매핑, 순서 유지, 숨김 필드 제외.
3. 정렬과 페이지 - 정렬 기준, 마지막 페이지, 범위 밖 클램프.
4. 정책 계산 - 날짜, 금액, 상태 전이. 정책 값을 바꾸면 깨지는 테스트 1건을 둔다 - 변경을 알아차리는 장치다.
5. 데이터 정합성 - 참조 키가 전부 존재하는지, 열거형 값이 정의 안에 있는지.
